# 架构说明：合成文档生成器

华为云版合成文档生成工具，将 PDF 转换为合成版本（去除 PII）。

## 架构图

```
用户终端
    │
    ▼
┌─────────────────────────────────────────────────────┐
│  pocsynth CLI (Python)                              │
│  ├─ PDF 解析 (PyMuPDF)                              │
│  ├─ 华为云 ModelArts (文档重写)                     │
│  │     ↕ AK/SK 认证                               │
│  │     ↕ ModelArts Studio API                      │
│  │        盘古系列 / Claude兼容模型                 │
│  │                                                   │
│  ├─ 华为云 NLP (PII 审计)                          │
│  │     ↕ AK/SK 认证                               │
│  │     ↕ NLP 实体识别 API                          │
│  │        人名/地址/证件/电话等实体                 │
│  │                                                   │
│  └─ 本地文件输出                                    │
│       ├─ *_cleaned.html (合成文档)                 │
│       ├─ *_pii_scan_audit.csv (PII审计报告)        │
│       └─ *_page_*.html/png (分页预览)               │
└─────────────────────────────────────────────────────┘
```

## 核心组件

| 组件 | 华为云服务 | 说明 |
|------|-----------|------|
| LLM 重写 | ModelArts Studio | 文档结构/格式保持，文本替换为合成内容 |
| PII 检测 | NLP 实体识别 | 自动检测人名/地址/证件等敏感信息 |
| SDK | 华为云 Python SDK | AK/SK 认证，会话管理 |

## 工作流程

1. **PDF 解析** → PyMuPDF 提取文本 + 页面图像
2. **重写** → ModelArts (Claude/盘古) 保持结构，替换文本为合成内容
3. **PII 审计** → NLP 实体识别扫描，输出审计 CSV
4. **输出** → 合成 HTML + 审计报告
